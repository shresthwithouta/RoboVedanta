## 🎨 Design Elements

### Color Coding

- **Golden (#B8860B)**: CTAs, headings, accents, form focus
- **Deep Blue (#002F5A)**: Backgrounds, cards
- **White**: Text, form inputs
- **Shimmer**: "STEM Education" heading

### Trust Indicators

- ✓ CBSE & ICSE Aligned badges
- ✓ NEP 2020 Compliant badge
- ✓ "Trusted by Schools" badge
- ✓ Shield icons for security/compliance
- ✓ Award icons for recognition

### Professional Tone Elements

- Institutional language ("Partner", "Implementation", "White-glove")
- B2B focused benefits (ROI, compliance, support)
- Structured timeline (reduces uncertainty)
- Complete solution emphasis (turnkey)
- No pricing (encourages inquiry)

## 📋 Form Fields

### Required (\*)

1. School Name
2. Contact Person
3. Email Address
4. Phone Number
5. Board Affiliation (dropdown)

### Optional

6. Student Count
7. Message/Requirements

### CTAs

- **Primary**: Submit Inquiry
- **Secondary**: Download Brochure

## 🎯 Conversion Strategy

### Trust Building

1. Compliance badges in hero
2. Structured implementation timeline
3. Dedicated account manager promise
4. White-glove service language

### Value Demonstration

1. 6 comprehensive offering cards
2. Chapter-to-project mapping examples
3. Complete solution stats (120+, 5, 7, 100%)
4. Support features showcase

### Easy Inquiry

1. Simple form (7 fields)
2. Multiple contact options
3. Privacy assurance
4. Download option (no form required)

## 🔒 Privacy & Professional Elements

- "We respect your privacy" message
- Professional email domain suggestion
- Institutional contact person field
- Board affiliation dropdown (shows understanding)
- Student count (helps with scoping)

## 📱 Responsive Behavior

- **Mobile**: Single column, stacked cards, full-width form
- **Tablet**: 2-column grids, side-by-side form fields
- **Desktop**: 3-column grids, optimized form layout

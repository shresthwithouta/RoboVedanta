## Color Coding

- **Golden (#B8860B)**: Headings, accents, buttons, borders
- **Deep Blue (#002F5A, #002850)**: Backgrounds, cards
- **White**: Text, labels
- **Shimmer Effect**: Animated gradient on key headings

## Animations

- ✨ Scroll-triggered reveals
- ✨ Hover scale effects on cards
- ✨ Animated progress bars
- ✨ Floating background orbs
- ✨ Particle motes effect

## Responsive Breakpoints

- Mobile: 1 column layouts
- Tablet (md): 2 column layouts
- Desktop (lg): 3-4 column layouts

## Interactive Elements

- All cards have hover effects (scale, glow, border color)
- Buttons have golden gradient on hover
- Links have animated underlines
- Icons rotate/scale on hover
- Progress bars animate on scroll into view
